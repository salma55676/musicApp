# Music App Project Specification

## Overview
This project is a mini web music app that allows users to search for songs using the Deezer API and play 30-second previews. The app displays results in visually appealing cards, showing the song title, artist, and album cover.

## Goals
- Enable users to search for songs by name.
- Fetch results dynamically from the Deezer API.
- Display songs as interactive cards with album cover, title, and artist.
- Play song previews directly in the app.
- Ensure responsive and clean UI for both desktop and mobile.

## Functional Requirements
1. Search input field to enter a song or artist name.
2. Dynamic fetching of song data from Deezer API.
3. Display results as cards with:
   - Album cover
   - Song title
   - Artist name
   - Play preview button
4. Handle cases with no results gracefully.
5. Responsive layout for different screen sizes.

## Non-Functional Requirements
- Use HTML, CSS, and vanilla JavaScript.
- Code should be well-structured and maintainable.
- Include clear documentation (README.md).
