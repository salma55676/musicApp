# Music App

## Description
This is a mini Music web app that allows users to search for songs and play 30-second previews. It fetches song data from the Deezer API and displays results as interactive cards with album cover, song title, and artist.

## Features
- Search songs by name
- Display results in card layout
- Play 30-second song previews
- Clean and responsive design

## Technologies Used
- HTML
- CSS
- JavaScript
- Deezer API

## How to Use
1. Open the app in a web browser.
2. Enter a song or artist name in the search bar.
3. Click "Search" to fetch results.
4. Play song previews using the play button on each card.
